OpenRouter models in Claude Code

Your models. Claude's picker.

Add OpenRouter favorites to Claude Code's native /model menu with one small, local CLI. No proxy or background service.

curl -LsSf https://xhluca.github.io/claude-openrouter/install.sh | sh

Run clor search claude to search the live catalog, clor select to choose favorites, and then switch normally with /model inside Claude Code.

Your OpenRouter key stays in a local mode-0600 credential file. Reset every setting owned by the tool with clor reset.
