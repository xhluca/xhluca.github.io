OpenRouter adapter for Meta Muse Code

Use your OpenRouter key in Muse Code.

Install a small local adapter, choose any available meta/muse* model, then keep using the normal muse command.

curl -LsSf https://xhluca.github.io/muse-code-openrouter/install.sh | sh
muse

$ muse --model meta/muse-spark-1.2

Model set to meta/muse-spark-1.2 · OpenRouter

› hello

◆ Hi — how can I help?

› /models

Model set to meta/muse-glimmer-30b · OpenRouter

› continue this conversation

◆ Still here — now using Glimmer.

✓ Model switched · conversation preserved · no 404

Switch models with /models. Check setup with muse-openrouter doctor --live. Revert everything with muse-openrouter uninstall.

Your key is stored locally in a mode-0600 file and the adapter listens only on 127.0.0.1.

Contributor model warning: Your prompts and outputs may be used to improve Meta’s products.
